# Authentication System

## Objective

The objective of this project is to create a simple and user-friendly authentication system that allows users to register, log in, and access a dashboard through a clean and responsive interface.

## Features

- User registration
- User login
- Form validation
- Password validation
- Authentication handling using JavaScript
- Dashboard access after successful login
- Logout functionality
- Responsive user interface
- Separate registration and login pages

## Technologies Used

- HTML5
- CSS3
- JavaScript
