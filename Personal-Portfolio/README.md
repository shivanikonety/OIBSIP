# Personal Portfolio

## Objective

The objective of this project is to create a personal portfolio website that showcases my skills, projects, education, and contact information using a clean and responsive design.

## Features

- Responsive portfolio design
- Navigation bar
- About Me section
- Skills section
- Projects section
- Education section
- Contact section
- Social media links
- Mobile-friendly layout

## Technologies Used

- HTML5
- CSS3
- JavaScript
