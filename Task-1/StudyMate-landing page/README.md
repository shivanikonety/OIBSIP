# Landing Page

## Objective

The objective of this project is to create a clean, responsive and visually appealing landing page using HTML5 and CSS3.

## Features

- Responsive landing page design
- Navigation bar
- Hero section
- Clear call-to-action
- Informative content sections
- Consistent color scheme
- Responsive layout for desktop and mobile devices

## Technologies Used

- HTML5
- CSS3
