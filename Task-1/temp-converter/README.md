# Temperature Converter

## Objective

The objective of this project is to create a simple and user-friendly temperature converter that allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin.

## Features

- Convert Celsius to Fahrenheit and Kelvin
- Convert Fahrenheit to Celsius and Kelvin
- Convert Kelvin to Celsius and Fahrenheit
- Simple and user-friendly interface
- Input validation
- Responsive design for desktop and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript
